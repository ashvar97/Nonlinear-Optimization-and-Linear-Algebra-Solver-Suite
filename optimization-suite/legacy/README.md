# Legacy lab variants

Earlier draft versions of two modules, kept for reference rather than deleted. They differ
slightly from the polished versions in `../optimization/` (extra CG iteration in
`PrecCGSolver_lab.py`; a marginally different backtracking condition in
`projectedBacktrackingSearch_lab.py`) but aren't part of the public package -- nothing imports
them, and they're not covered by the test suite.
